# Flujo: creación

1. Leer estructura, marca, contenido, diseño, sitemap y referencias.
2. Consultar `docs/DOCUMENTATION_GOVERNANCE.md` y preparar la documentación del módulo o proyecto desde el inicio.
3. Definir objetivo, usuario, estado vacío, carga, error y éxito.
4. Reutilizar tokens y patrones existentes antes de crear variantes.
5. Separar datos ficticios, lógica, interfaz y estilos.
6. Crear copia en español latinoamericano e inglés desde el inicio.
7. Actualizar `CHANGELOG.md`, `docs/modules/`, README, manual, sitemap, diseño, contenido, calidad y referencias según la matriz.
8. Validar documentación, responsive, accesibilidad, rendimiento, tipos, lint y build.

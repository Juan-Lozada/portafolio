# Flujo: corrección

1. Reproducir el problema y registrar resultado esperado versus resultado real.
2. Leer la implementación completa y sus estilos antes de editar.
3. Encontrar la causa raíz; no ocultar síntomas con temporizadores o recargas.
4. Consultar `docs/DOCUMENTATION_GOVERNANCE.md` y determinar qué contrato o explicación quedó desactualizado.
5. Corregir sin alterar flujos no relacionados.
6. Probar el caso original, regresiones cercanas, móvil y accesibilidad.
7. Actualizar `CHANGELOG.md` y la documentación del módulo; registrar la causa raíz cuando aporte mantenimiento o valor para entrevistas.
8. Ejecutar `npm run docs:check`, `npm run check` y `npm run build`.

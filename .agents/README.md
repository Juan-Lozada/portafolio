# Sistema de trabajo para agentes

Esta carpeta convierte las decisiones del proyecto en reglas repetibles. `AGENTS.md` define la política general; `skills/` contiene criterios especializados; `workflows/` explica cómo ejecutar cambios, correcciones y creaciones.

Todos los workflows exigen consultar `docs/DOCUMENTATION_GOVERNANCE.md`, actualizar `CHANGELOG.md` y sincronizar los documentos relacionados dentro de la misma entrega. Esta regla también aplica al modificar reglas, skills, workflows o prompts.

Antes de actuar, identificar el tipo de tarea, leer la estructura actual del módulo afectado y usar el flujo correspondiente. Ningún flujo autoriza publicación, uso de datos reales o cambios destructivos.

# Prompts del proyecto

Cada carpeta contiene prompts de cambio, corrección y creación adaptados al contexto del proyecto. Antes de usarlos, reemplazar el objetivo entre corchetes. Todos obligan a leer la estructura vigente, AGENTS.md, la skill de español y la documentación.

Todo prompt hereda la regla crítica de documentación: consultar `docs/DOCUMENTATION_GOVERNANCE.md`, actualizar `CHANGELOG.md`, modificar los documentos relacionados y declarar cuáles se revisaron sin cambios. Una implementación sin esta evidencia permanece incompleta.

- `portfolio/`: landing y sistema compartido.
- `observa/`: datos, mapas, gráficas y CRUD.
- `ruta/`: futura operación de flota.
- `mesa/`: futura experiencia de pagos con QR.

# Contribuir

1. Crear una historia con problema, resultado y criterios de aceptación.
2. Trabajar en una rama `feature/`, `fix/` o `docs/`.
3. Consultar `docs/DOCUMENTATION_GOVERNANCE.md` y definir el impacto documental.
4. Actualizar `CHANGELOG.md` y todos los documentos relacionados dentro del mismo cambio.
5. Mantener los cambios pequeños, bilingües y libres de datos reales.
6. Ejecutar `npm run docs:check`, `npm run check` y `npm run build`.
7. Abrir una solicitud usando la plantilla, declarar documentos revisados y adjuntar evidencia proporcional.

Las decisiones de contenido siguen `.agents/skills/espanol-latinoamerica/SKILL.md`; los cambios visuales deben respetar `docs/BRAND.md` y `docs/DESIGN.md`.

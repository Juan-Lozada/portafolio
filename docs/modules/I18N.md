# Módulo: idiomas

El español latinoamericano (`es-419`) es el idioma predeterminado. `LocaleProvider` mantiene la preferencia local y actualiza el atributo `lang` del documento; cada módulo usa `copy(español, inglés)` para entregar equivalentes completos.

Todo cambio de contenido debe revisar tildes, signos de apertura, concordancia, nombres técnicos y paridad funcional en inglés. Las reglas completas están en `.agents/skills/espanol-latinoamerica/SKILL.md`.
